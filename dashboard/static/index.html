HELP how to use this platform, step by step

What does this platform do?

You give it a website you own. It quietly looks at the outside of that website and reports: which website names belong to it, which ones are online, which technical doors (ports) are open -- and it tells you what changed since the last time. It only ever looks at targets you have explicitly allowed.

First time here? Three steps.

1. SETTINGS -- type your Telegram username or numeric id where it says TELEGRAM, then press SEND TEST NOTIFICATION. A test message should arrive within seconds.
2. TARGETS -- add your website (for example example.com). This is also where each website gets its own Telegram setting.
3. RUN CONTROL -- type the website name and press START. Watch the progress live, then open RESULTS and REPORTS.

Reading the results

RESULTS lists every discovered address with filters and "new since last time" badges. REPORTS builds a clean, tamper-checked report (web page, PDF, CSV, JSON) with one press of GENERATE NOW.

Telegram alerts

You only ever set your own username (like jackjohns) or numeric id. The bot key itself is provisioned once by the installer in the .env file. Each website can have its own receiver or be muted entirely -- see TARGETS. Personal usernames deliver after you open your bot in Telegram and press START once; the platform learns your chat automatically. Public channel handles (@teamname) work immediately.

Checking several websites at once

FLEET runs a group of your registered targets in parallel, each in its own isolated workspace with its own settings.

Spreading the load (IP rotation)

SETTINGS accepts a comma-separated PROXY POOL. Every discovery step goes out through the next entry in turn, so one address never carries the whole scan. Each entry is health-checked before the run starts, and the run's log records which proxy each step used.

Letting it watch for you

RUN CONTROL has a scheduler: set an interval (10 minutes minimum) and the platform checks the website by itself and sends a Telegram message when something changes.

Safety rules

Only scan websites you own or have written permission to test. The platform refuses anything that is not on its allow-list -- that is there to protect you.

The full manual with pictures-level detail lives in docs/HELP.md in the project folder.
